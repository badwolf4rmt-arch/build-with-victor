# Roadmap

- [x] Перевести генерацию викторин и картинок на OpenRouter (ключ пользователя, google/gemini-3.1-pro-preview для текста, google/gemini-3-pro-image для картинок)
- [x] Общая библиотека в облаке: викторины, обложки и папки одинаковы на всех компьютерах
- [x] В окне генерации поля «Предмет» и «Класс» на одной линии
- [x] Убрать синюю подсказку и лишние подписи в окне генерации, счётчик символов в поле учебного текста (лимит 20000)
- [x] Поле загрузки файла оформить по макету: пунктирная зона, подсказки о размере и форматах, кнопка «Выбрать файл»
- [x] Добавить предмет, класс и тему в ручное создание викторины (редактор + сохранение в облако)
- [x] Иллюстрации к ~30% вопросов при ИИ-генерации по правилам и стилю из документа (описание: google/gemini-2.5-flash, картинка: google/gemini-3.1-flash-image)
- [x] Равномерно распределять иллюстрации: минимум одна картинка в каждом блоке из трёх вопросов
- [x] Предпросмотр и игровое поле по макету Figma (страница предпросмотра, карточки со звездой, плашки команд, запрет запуска на телефоне)
- [x] Выдача викторины ученикам по QR-коду: ответы с устройств, результаты у учителя (темп и учёт скорости — в расширенных настройках)
- [x] Разрешить ученику менять ответ до показа правильного ответа, сохраняя только последний выбор
- [x] Адаптировать экран вопроса ученика под ширину и высоту устройства без прокрутки
